# Circuito Somador de 32 Bits Defeituoso (XOR)

## 📌 Descrição

Simulação de um circuito somador de 32 bits defeituoso, onde o carregador de bit (carry) possui saída constante igual a zero. O problema propõe o cálculo da soma aritmética de dois números decimais de 32 bits sem sinal sob a lógica da porta lógica XOR (adição sem transporte de vai-um).

## 📋 Regras do Negócio

### Operação Sem Carry

A adição de cada par de bits deve ocorrer sem propagar o vai-um (carry). O comportamento do circuito defeituoso equivale exatamente à operação lógica de "Ou Exclusivo" (XOR).

### Manipulação de 32 Bits Sem Sinal

Os valores de entrada devem ser tratados como inteiros de 32 bits sem sinal, garantindo que o processamento respeite o escopo numérico do circuito digital simulado.

#### Regras de Operação

- **Bits iguais (0+0 ou 1+1):** O resultado na posição do bit correspondente deve ser 0.
- **Bits diferentes (0+1 ou 1+0):** O resultado na posição do bit correspondente deve ser 1.

## 📥 Estrutura de Entrada

- **Pares de Inteiros:** Em cada linha de entrada haverá um par de inteiros de 32 bits sem sinal, separados por um único espaço.
- **Corpo/Linhas seguintes:** Leitura linha por linha via fluxo padrão de entrada (`stdin`).
- **Critério de parada:** A entrada termina com EOF (End of File).

## 📤 Estrutura de Saída

Para cada linha de entrada, o programa deve fornecer uma linha de saída contendo o valor decimal resultante após somar os dois números no modo "Mofiz" (operação XOR).

## 🧪 Exemplo de Teste

### Entrada:

```
4 6
6 9
```

### Saída Esperada:

```
2
15
```

## 💡 Explicação

### Primeiro exemplo: 4 XOR 6 = 2

```
  4 = 0100 (binário)
  6 = 0110 (binário)
  ---------
XOR = 0010 (binário) = 2 (decimal)
```

**Processamento bit a bit:**

- Posição 0: 0 XOR 0 = 0
- Posição 1: 1 XOR 1 = 0
- Posição 2: 1 XOR 0 = 1
- Posição 3: 0 XOR 0 = 0

### Segundo exemplo: 6 XOR 9 = 15

```
  6 = 0110 (binário)
  9 = 1001 (binário)
  ---------
XOR = 1111 (binário) = 15 (decimal)
```

**Processamento bit a bit:**

- Posição 0: 0 XOR 1 = 1
- Posição 1: 1 XOR 0 = 1
- Posição 2: 1 XOR 0 = 1
- Posição 3: 0 XOR 1 = 1

## 🔧 Solução

A solução utiliza o operador bitwise XOR (`^`) nativo da linguagem Dart:

```dart
final result = a ^ b;
```

Este operador realiza a operação XOR bit a bit entre os dois números, simulando perfeitamente o comportamento do circuito defeituoso.

## ✅ Critérios de Aceite

- ✅ O algoritmo processa pares de inteiros de forma iterativa até atingir o final do arquivo (EOF)
- ✅ Uso eficiente do operador bitwise XOR (`^`) nativo da linguagem Dart
- ✅ Computação da soma sem carry em tempo hábil e dentro do limite de memória
- ✅ Resultado decimal exibido corretamente para cada par de entrada

## 🧩 Complexidade

- **Tempo:** O(n) - onde n é o número de pares na entrada
- **Espaço:** O(1) - apenas constantes armazenadas em memória

## 📚 Conceitos Utilizados

- Operadores bitwise (XOR)
- Leitura de entrada padrão (stdin)
- Processamento até EOF
- Manipulação de inteiros de 32 bits
