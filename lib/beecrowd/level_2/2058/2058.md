# 2058 - Triângulos e Polígonos Regulares

## Contexto

O professor Rafael adora computação gráfica. Ele gosta muito de renderizar objetos, especialmente bonecas. Mas ele não gosta de desenhar polígonos regulares usando triângulos. Fazer isso consiste em compor um polígono regular usando apenas triângulos, de forma que os triângulos não se interceptem e se utilize o menor número possível de triângulos na composição. Veja um quadrado e um pentágono com os triângulos na figura.

Poligonos

O professor Rafael pediu para você calcular qual o número mínimo de triângulos necessários para compor um polígono regular de N lados.

### Entrada

A entrada é composta por um número N (3 ≤ N ≤ 109), que indica o número de lados de um polígono regular.

### Saída

A saída é o número mínimo de triângulos necessários para compor um polígono regular de N lados.

## Forma de resolução

Implementa fórmula geométrica simples: número mínimo de triângulos = número de lados - 2.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve **geometria combinatória**:

- **Triangulação de polígonos**: Decompor polígono em triângulos não sobrepostos
- **Padrão matemático**: Polígono com N lados pode ser dividido em N-2 triângulos
- **Prova intuitiva**: 
  - Quadrilátero (4 lados): 2 triângulos
  - Pentágono (5 lados): 3 triângulos
  - Hexágono (6 lados): 4 triângulos
- **Fórmula geral**: Triângulos = N - 2

### Abordagem da Solução

1. Ler N (número de lados)
2. Calcular: `triângulos = N - 2`
3. Imprimir resultado

### Exemplo Passo a Passo

**Entrada:**
```
5
```

**Processamento:**
- N = 5 (pentágono)
- Triângulos = 5 - 2 = 3
- Verificação visual: Um pentágono pode ser dividido em 3 triângulos

**Saída:**
```
3
```

**Outro exemplo:**

**Entrada:**
```
10
```

**Processamento:**
- N = 10 (decágono)
- Triângulos = 10 - 2 = 8

**Saída:**
```
8
```

### Implementação em Dart

A implementação utiliza:

- **Leitura simples**: Um inteiro
- **Subtração**: `n - 2`
- **Print direto**: Resultado inteiro sem formatação

### Complexidade

- **Tempo**: O(1) - operação aritmética simples
- **Espaço**: O(1) - uma variável inteira
