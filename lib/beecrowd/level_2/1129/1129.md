# Leitura Ótica

## Problema

Maratona de Programação da SBC - Brasil

**Tempo limite: 1s**

O professor João está implementando um sistema de leitura ótica para processar folhas de respostas de múltipla escolha. Cada questão tem cinco alternativas (A, B, C, D, E), e após escanear as folhas, o sistema calcula a média dos tons de cinza para cada quadrado de resposta, onde:

- 0 = preto total (preenchido)
- 255 = branco total (não preenchido)

A classificação é feita por um limiar de 127:

- **≤ 127**: considerado preto (alternativa marcada)
- **> 127**: considerado branco (alternativa não marcada)

Uma resposta é válida apenas se **exatamente uma alternativa** estiver marcada. Caso contrário, deve ser desconsiderada.

## Entrada

- Primeira linha de cada caso: inteiro **N** (1 ≤ N ≤ 255) - número de questões
- Próximas N linhas: cinco inteiros **A**, **B**, **C**, **D**, **E** (0 ≤ valores ≤ 255)
- Entrada termina com N = 0

## Saída

Para cada questão:

- Se exatamente uma alternativa marcada: imprimir a letra (A/B/C/D/E)
- Caso contrário: imprimir '\*' (asterisco)

## Exemplos

### Exemplo 1

**Entrada:**

```
3
255 0 255 255 255
100 100 100 100 100
50 150 50 150 50
0
```

**Saída:**

```
B
*
*
```

**Explicação:**

- Questão 1: Apenas B marcado (0 ≤ 127) → resposta: B
- Questão 2: Todas as cinco alternativas estão marcadas (100 ≤ 127) → resposta: \*
- Questão 3: Múltiplas alternativas marcadas → resposta: \*

## Solução

A solução percorre cada questão contando quantos valores são ≤ 127 (pretos). Se exatamente um valor atender ao critério, esse é o índice da alternativa correta.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve **processamento de imagem digital e reconhecimento de padrões**:

- **Valor de pixel**: Tons de cinza (0-255)
- **Limiar de binarização**: 127 (valores ≤ 127 são pretos/marcados)
- **Validação**: Exatamente 1 alternativa marcada
- **Casos de erro**: 0 ou múltiplas alternativas marcadas → resposta inválida
- **Entrada múltipla**: Múltiplos casos até N=0

### Abordagem da Solução

1. Loop enquanto N > 0:
   a. Ler N (número de questões)
   b. Para cada questão:
      - Ler 5 valores de tons de cinza
      - Contar quantos são ≤ 127
      - Se count = 1: imprimir letra da alternativa
      - Se count ≠ 1: imprimir '*'

### Exemplo Passo a Passo

**Entrada:**
```
3
255 0 255 255 255
100 100 100 100 100
50 150 50 150 50
0
```

**Questão 1: [255, 0, 255, 255, 255]**
- Índice 0 (A): 255 > 127 (branco)
- Índice 1 (B): 0 ≤ 127 (preto) ← marcado
- Índice 2 (C): 255 > 127 (branco)
- Índice 3 (D): 255 > 127 (branco)
- Índice 4 (E): 255 > 127 (branco)
- Count: 1 (exatamente um) → Resposta: B

**Questão 2: [100, 100, 100, 100, 100]**
- Todos: 100 ≤ 127 (todos pretos) ← Erro!
- Count: 5 (não é 1) → Resposta: *

**Questão 3: [50, 150, 50, 150, 50]**
- Múltiplas alternativas pretas
- Count: 3 (não é 1) → Resposta: *

### Implementação em Dart

A implementação utiliza:

- **Loop externo**: `while(true)` com quebra quando N = 0
- **Parsing de linha**: `split(' ').map(int.parse).toList()`
- **Lista de letras**: `['A', 'B', 'C', 'D', 'E']` para mapeamento
- **Contagem**: Loop for-loop com condição `if (values[j] <= 127)`
- **Condicional final**: Se count = 1, imprimir letra; senão, '*'

### Complexidade

- **Tempo**: O(N × 5) = O(N) - N questões com 5 alternativas cada
- **Espaço**: O(1) - variáveis temporárias apenas
