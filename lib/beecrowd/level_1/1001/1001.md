# 1001 - Extremamente Básico

## Contexto

Leia 2 valores inteiros e armazene-os nas variáveis A e B. Efetue a soma de A e B atribuindo o seu resultado na variável X. Imprima X conforme exemplo apresentado abaixo. Não apresente mensagem alguma além daquilo que está sendo especificado e não esqueça de imprimir o fim de linha após o resultado, caso contrário, você receberá "Presentation Error".

### Entrada

A entrada contém 2 valores inteiros.

### Saída

Imprima a mensagem "X = " (letra X maiúscula) seguido pelo valor da variável X e pelo final de linha. Cuide para que tenha um espaço antes e depois do sinal de igualdade, conforme o exemplo abaixo.

## Forma de resolução

Lê dois inteiros da entrada, realiza a soma e imprime o resultado no formato especificado.

## Descrição da Resolução

### Pensamento do Problema

Este problema introduz os conceitos fundamentais de entrada e saída:

- **Entrada múltipla**: Ler dados em linhas separadas usando `stdin.readLineSync()`
- **Conversão de tipo**: Converter strings em inteiros com `int.parse()`
- **Formatação de saída**: Usar interpolação de string para incluir variáveis
- **Exatidão sintática**: A formatação deve ser exata: "X = " (com espaços)

### Abordagem da Solução

1. Ler primeira linha e converter para inteiro em `num1`
2. Ler segunda linha e converter para inteiro em `num2`
3. Calcular soma: `num1 + num2`
4. Imprimir usando interpolação: `'X = ${num1 + num2}'`

### Exemplo Passo a Passo

**Entrada:**
```
10
20
```

**Processamento:**
- `num1 = int.parse("10")` → 10
- `num2 = int.parse("20")` → 20
- Soma: 10 + 20 = 30

**Saída:**
```
X = 30
```

### Implementação em Dart

A implementação utiliza:

- **Entrada**: `stdin.readLineSync()!` com operador `!` para garantir não-nulo
- **Conversão**: `int.parse()` converte string em inteiro
- **Interpolação**: `${expressão}` dentro de strings
- **Print**: Automaticamente adiciona quebra de linha

### Complexidade

- **Tempo**: O(1) - leitura e soma são operações constantes
- **Espaço**: O(1) - apenas duas variáveis inteiras
