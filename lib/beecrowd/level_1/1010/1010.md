# 1010 - Cálculo Simples

## Contexto

Neste problema, deve-se ler o código de uma peça 1, o número de peças 1, o valor unitário de cada peça 1, o código de uma peça 2, o número de peças 2 e o valor unitário de cada peça 2. Após, calcule e mostre o valor a ser pago.

### Entrada

O arquivo de entrada contém duas linhas de dados. Em cada linha haverá 3 valores, respectivamente dois inteiros e um valor com 2 casas decimais.

### Saída

A saída deverá ser uma mensagem conforme o exemplo fornecido abaixo, lembrando de deixar um espaço após os dois pontos e um espaço após o "R$". O valor deverá ser apresentado com 2 casas após o ponto.

## Forma de resolução

Lê duas linhas de entrada, divide cada uma em componentes usando `split()`, realiza cálculo de custo total de produtos e formata a saída com `toStringAsFixed(2)`.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve operações comerciais básicas:

- **Entrada estruturada**: 2 linhas com 3 valores cada (código é ignorado)
- **Parsing complexo**: Dividir string em componentes com `split(' ')`
- **Cálculo**: Custo total = (qtd1 × valor1) + (qtd2 × valor2)
- **Formatação monetária**: 2 casas decimais com símbolo R$

### Abordagem da Solução

1. Ler primeira linha e dividir em 3 componentes
2. Extrair quantidade e valor (ignorar código)
3. Ler segunda linha e repetir processo
4. Calcular total: `(qtd1 × valor1) + (qtd2 × valor2)`
5. Formatar e imprimir com símbolo monetário

### Exemplo Passo a Passo

**Entrada:**
```
1 2 5.50
2 3 10.00
```

**Processamento:**
- Linha 1: código=1 (ignorado), qtd=2, valor=5.50 → custo = 2 × 5.50 = 11.00
- Linha 2: código=2 (ignorado), qtd=3, valor=10.00 → custo = 3 × 10.00 = 30.00
- Total: 11.00 + 30.00 = 41.00

**Saída:**
```
VALOR A PAGAR: R$ 41.00
```

### Implementação em Dart

A implementação utiliza:

- **split()**: Divide string por espaço em componentes
- **List<String>**: Armazena os componentes
- **Índices**: [0]=código, [1]=quantidade, [2]=valor
- **Parsing**: Conversão de índices [1] e [2] para int e double
- **Escape**: Barra invertida `\$` para imprimir símbolo literal

### Complexidade

- **Tempo**: O(1) - 2 linhas com operações constantes cada
- **Espaço**: O(1) - 4 variáveis numéricas
