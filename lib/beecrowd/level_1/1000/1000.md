# 1000 - Hello World

## Contexto

Bem-vindo ao beecrowd!

O seu primeiro programa em qualquer linguagem de programação normalmente é o "Hello World!". Neste primeiro problema tudo o que você precisa fazer é imprimir esta mensagem na tela.

### Entrada

Este problema não possui nenhuma entrada.

### Saída

Você deve imprimir a mensagem "Hello World!" e em seguida o final de linha, conforme o exemplo abaixo.

## Forma de resolução

Implementa uma solução direta usando `print()` para exibir a mensagem padrão de "Hello World!".

## Descrição da Resolução

### Pensamento do Problema

Este é o problema inaugural de programação, que introduz a sintaxe básica da linguagem Dart. A simplicidade é proposital:

- Sem entrada: O programa não processa dados de entrada
- Saída fixa: Uma mensagem literal deve ser exibida
- Teste de ambiente: Valida que o compilador/interpretador está funcionando corretamente

### Abordagem da Solução

A solução é trivial e consiste em:

1. Usar a função `print()` do Dart, que escreve texto no console e adiciona uma quebra de linha automaticamente
2. Passar a string `'Hello World!'` como argumento
3. O programa executa e encerra

### Exemplo Passo a Passo

Quando o programa é executado:

```
Entrada: (sem entrada)
Execução: print('Hello World!') é chamado
Saída: Hello World!
```

### Implementação em Dart

A implementação utiliza:

- **Função `main()`**: Ponto de entrada do programa Dart
- **String literal**: `'Hello World!'` com aspas simples
- **Função `print()`**: Escreve a string e adiciona quebra de linha automaticamente

### Complexidade

- **Tempo**: O(1) - operação constante
- **Espaço**: O(1) - sem estruturas de dados dinâmicas
