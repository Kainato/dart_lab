# 1002 - Área do círculo

## Contexto

A fórmula para calcular a área de uma circunferência é: area = π . raio2. Considerando para este problema que π = 3.14159:

- Efetue o cálculo da área, elevando o valor de raio ao quadrado e multiplicando por π.

### Entrada

A entrada contém um valor de ponto flutuante (dupla precisão), no caso, a variável raio.

### Saída

Apresentar a mensagem "A=" seguido pelo valor da variável area, conforme exemplo abaixo, com 4 casas após o ponto decimal. Utilize variáveis de dupla precisão (double). Como todos os problemas, não esqueça de imprimir o fim de linha após o resultado, caso contrário, você receberá "Presentation Error".

## Forma de resolução

Calcula a área de um círculo usando a fórmula A = π × r². Aplica parsing de entrada com `double.parse()` e formatação de saída com `toStringAsFixed(4)` para 4 casas decimais.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve cálculo matemático com ponto flutuante:

- **Precisão**: Trabalhar com números `double` (64 bits)
- **Formatação de saída**: Exatamente 4 casas decimais
- **Fórmula matemática**: A = π × r²
- **Constante π**: Fornecida como 3.14159 (não usar Math.PI)

### Abordagem da Solução

1. Ler valor de ponto flutuante do raio
2. Calcular: `area = 3.14159 × raio × raio`
3. Formatar com 4 casas decimais usando `toStringAsFixed(4)`
4. Imprimir com prefixo "A="

### Exemplo Passo a Passo

**Entrada:**
```
2.0
```

**Processamento:**
- `raio = double.parse("2.0")` → 2.0
- `area = 3.14159 × 2.0 × 2.0` → 12.56636
- `toStringAsFixed(4)` → "12.5664"

**Saída:**
```
A=12.5664
```

### Implementação em Dart

A implementação utiliza:

- **Tipo**: `double` para precisão de ponto flutuante
- **Cálculo**: Multiplicação direta: `3.14159 * raio * raio`
- **Formatação**: `toStringAsFixed(4)` garante exatamente 4 casas decimais com arredondamento
- **String interpolation**: `'A=${area.toStringAsFixed(4)}'`

### Complexidade

- **Tempo**: O(1) - operação constante
- **Espaço**: O(1) - apenas duas variáveis double
