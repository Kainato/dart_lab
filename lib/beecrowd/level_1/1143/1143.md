# 1143 - Quadrado e ao Cubo

## Contexto

Escreva um programa que leia um valor inteiro N (1 < N < 1000). Este N é a quantidade de linhas de saída que serão apresentadas na execução do programa.

### Entrada

O arquivo de entrada contém um número inteiro positivo N.

### Saída

Imprima a saída conforme o exemplo fornecido.

## Forma de resolução

Loop de 1 até n calculando quadrado (i²) e cubo (i³) para cada iteração. Imprime os 3 valores em sequência.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve iteração e cálculos aritméticos:

- **Loop**: De 1 até N (inclusive)
- **Operações**: Calcular quadrado (i²) e cubo (i³) para cada i
- **Saída**: 3 valores por linha separados por espaço

### Abordagem da Solução

1. Ler N
2. Loop de i = 1 até N:
   a. Calcular quadrado: i × i
   b. Calcular cubo: i × i × i
   c. Imprimir: i, quadrado, cubo separados por espaço

### Exemplo Passo a Passo

**Entrada:**
```
3
```

**Processamento:**
- i = 1: quadrado = 1, cubo = 1 → "1 1 1"
- i = 2: quadrado = 4, cubo = 8 → "2 4 8"
- i = 3: quadrado = 9, cubo = 27 → "3 9 27"

**Saída:**
```
1 1 1
2 4 8
3 9 27
```

### Implementação em Dart

A implementação utiliza:

- **Loop for**: `for (int i = 1; i <= n; i++)`
- **Cálculos diretos**: `i * i` e `i * i * i`
- **String interpolation**: `'$i $quadrado $cubo'`
- **Print**: Automaticamente adiciona quebra de linha

### Complexidade

- **Tempo**: O(N) - loop executado N vezes
- **Espaço**: O(1) - apenas variáveis locais (não conta output)
