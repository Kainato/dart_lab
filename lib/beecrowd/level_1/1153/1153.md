# 1153 - Fatorial Simples

## Contexto

Ler um valor N. Calcular e escrever seu respectivo fatorial. Fatorial de `N = N × (N-1) × (N-2) × (N-3) × ... × 1.`

### Entrada

A entrada contém um valor inteiro N (0 < N < 13).

### Saída

A saída contém um valor inteiro, correspondente ao fatorial de N.

## Forma de resolução

Implementa cálculo iterativo de fatorial usando loop e multiplicação acumulativa: `1×2×3×...×n.`
## Descrição da Resolução

### Pensamento do Problema

Este problema introduz o conceito de **fatorial** (N!):

- **Definição**: N! = N × (N-1) × (N-2) × ... × 1
- **Casos especiais**: 0! = 1 (não aparece neste problema pois N > 0)
- **Restrição**: N < 13 garante que resultado cabe em int (12! = 479,001,600)
- **Padrão**: Acumular multiplicações em loop

### Abordagem da Solução

1. Ler N
2. Inicializar resultado = 1
3. Loop de i = 1 até N:
   a. Multiplicar resultado por i: `resultado *= i`
4. Imprimir resultado

### Exemplo Passo a Passo

**Entrada:**
```
5
```

**Processamento:**
- resultadoFatorial = 1
- i = 1: resultado = 1 × 1 = 1
- i = 2: resultado = 1 × 2 = 2
- i = 3: resultado = 2 × 3 = 6
- i = 4: resultado = 6 × 4 = 24
- i = 5: resultado = 24 × 5 = 120

**Saída:**
```
120
```

### Implementação em Dart

A implementação utiliza:

- **Inicialização**: `int resultadoFatorial = 1`
- **Loop for**: `for (int i = 1; i <= n; i++)`
- **Operador compound**: `resultadoFatorial *= i` equivalente a `resultado = resultado * i`
- **Output simples**: Apenas o número sem formatação

### Complexidade

- **Tempo**: O(N) - loop executado N vezes
- **Espaço**: O(1) - uma variável inteira
