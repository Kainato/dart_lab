# 1116 - Dividindo X por Y

## Contexto

Escreva um algoritmo que leia 2 números e imprima o resultado da divisão do primeiro pelo segundo. Caso não for possível mostre a mensagem “divisao impossivel” para os valores em questão.

### Entrada

A entrada contém um número inteiro N. Este N será a quantidade de pares de valores inteiros (X e Y) que serão lidos em seguida.

### Saída

Para cada caso mostre o resultado da divisão com um dígito após o ponto decimal, ou “divisao impossivel” caso não seja possível efetuar o cálculo.
Obs.: Cuide que a divisão entre dois inteiros em algumas linguagens como o C e C++ gera outro inteiro. Utilize cast :)

## Forma de resolução

Lê quantidade de casos de teste. Para cada caso, divide dois números e verifica divisão por zero, formatando resultado com `toStringAsFixed(1)` ou retornando mensagem de erro.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve tratamento de exceções e validação:

- **Múltiplos casos**: N pares de números
- **Validação**: Verificar se Y = 0 (divisão por zero)
- **Conversão de tipo**: Inteiros para double para divisão precisa
- **Formatação**: 1 casa decimal ou mensagem de erro

### Abordagem da Solução

1. Ler quantidade de casos N
2. Loop N vezes:
   a. Ler X e Y como inteiros
   b. Verificar se Y = 0
   c. Se Y = 0: imprimir "divisao impossivel"
   d. Senão: converter para double, dividir e imprimir com 1 casa

### Exemplo Passo a Passo

**Entrada:**
```
4
10 2
10 0
5 3
-8 2
```

**Processamento:**
- Caso 1: 10 ÷ 2 = 5.0 → "5.0"
- Caso 2: 10 ÷ 0 → impossível → "divisao impossivel"
- Caso 3: 5 ÷ 3 = 1.666... → "1.7" (arredonda para 1 casa)
- Caso 4: -8 ÷ 2 = -4.0 → "-4.0"

**Saída:**
```
5.0
divisao impossivel
1.7
-4.0
```

### Implementação em Dart

A implementação utiliza:

- **Loop for**: Itera N vezes
- **Validação**: `if (y == 0)` antes de dividir
- **Cast implícito**: Dart infere conversão em `(x / y)` (x e y são int, resultado é double)
- **Formatação**: `toStringAsFixed(1)` para 1 casa decimal
- **String interpolation**: `'${resultado}'`

### Complexidade

- **Tempo**: O(N) onde N é a quantidade de casos
- **Espaço**: O(1) - apenas variáveis temporárias
