# 1043 - Triângulo

## Contexto

Leia 3 valores reais (A, B e C) e verifique se eles formam ou não um triângulo. Em caso positivo, calcule o perímetro do triângulo e apresente a mensagem:

Perimetro = XX.X

Em caso negativo, calcule a área do trapézio que tem A e B como base e C como altura, mostrando a mensagem

Area = XX.X

### Entrada

A entrada contém três valores reais.

### Saída

O resultado deve ser apresentado com uma casa decimal.

## Forma de resolução

Ordena 3 lados em ordem decrescente usando `sort()` com comparador customizado. Verifica se formam um triângulo usando desigualdade triangular e calcula perímetro ou área do trapézio conforme aplicável.

## Descrição da Resolução

### Pensamento do Problema

Este problema combina geometria e lógica condicional:

- **Desigualdade Triangular**: Para 3 lados formar triângulo, a soma de dois menores deve ser > maior
- **Ordenação**: Necessário ordenar para facilitar a verificação (comparar apenas maior com soma dos outros)
- **Casos**: Se triângulo → perímetro; Senão → área de trapézio
- **Precisão**: 1 casa decimal em ambos os casos

### Abordagem da Solução

1. Ler 3 valores e armazenar em lista
2. Ordenar em ordem decrescente
3. Verificar: `lados[0] < lados[1] + lados[2]` (maior < soma dos outros)
4. Se verdadeiro: calcular perímetro = l1 + l2 + l3
5. Se falso: calcular área do trapézio = `(l1 + l2) × l3 / 2`
6. Imprimir com 1 casa decimal

### Exemplo Passo a Passo

**Caso 1 - Triângulo válido:**

**Entrada:**
```
6.0 8.0 10.0
```

**Processamento:**
- Lados: [6.0, 8.0, 10.0]
- Ordenado decrescente: [10.0, 8.0, 6.0]
- Verificação: 10.0 < 8.0 + 6.0 → 10.0 < 14.0 ✓ (é triângulo)
- Perímetro: 10.0 + 8.0 + 6.0 = 24.0

**Saída:**
```
Perimetro = 24.0
```

**Caso 2 - Não é triângulo:**

**Entrada:**
```
1.0 2.0 10.0
```

**Processamento:**
- Lados: [1.0, 2.0, 10.0]
- Ordenado decrescente: [10.0, 2.0, 1.0]
- Verificação: 10.0 < 2.0 + 1.0 → 10.0 < 3.0 ✗ (NÃO é triângulo)
- Área trapézio: (10.0 + 2.0) × 1.0 / 2 = 6.0

**Saída:**
```
Area = 6.0
```

### Implementação em Dart

A implementação utiliza:

- **List.map()**: Converte strings para doubles
- **sort() com comparador**: `(a, b) => b.compareTo(a)` para ordem decrescente
- **Acesso por índice**: `lados[0]`, `lados[1]`, `lados[2]`
- **Condicional**: `if/else` para decidir cálculo
- **Formatação**: `toStringAsFixed(1)` para 1 casa decimal

### Complexidade

- **Tempo**: O(1) - 3 elementos com sort O(3 log 3) = O(1) constante
- **Espaço**: O(1) - lista de 3 elementos
