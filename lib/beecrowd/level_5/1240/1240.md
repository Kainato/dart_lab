# 1240 - Encaixa ou Não I

## Contexto

Paulinho tem em suas mãos um pequeno problema. A professora lhe pediu que ele construísse um programa para verificar, à partir de dois valores inteiros A e B, se B corresponde aos últimos dígitos de A.

### Entrada

A entrada consiste de vários casos de teste. A primeira linha de entrada contém um inteiro N que indica a quantidade de casos de teste. Cada caso de teste consiste de dois inteiros A (1 ≤ A < 231 ) e B (1 ≤ B < 231) positivos.

### Saída

Para cada caso de entrada imprima uma mensagem indicando se o segundo valor encaixa no primeiro valor

## Forma de resolução

Lê múltiplos casos de teste. Para cada caso, compara se string B é sufixo de string A usando método `endsWith()`.

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve **comparação de strings e sufixos**:

- **Conversão**: Inteiros são tratados como strings para comparação
- **Sufixo**: B deve ser os últimos dígitos de A
- **Exemplo**: A=123456, B=456 → SIM (456 são últimos dígitos)
- **Exemplo**: A=123456, B=234 → NÃO (234 está no meio, não no final)
- **Método ideal**: `String.endsWith()` nativa de Dart

### Abordagem da Solução

1. Ler N (número de casos)
2. Loop N vezes:
   a. Ler A e B como strings (não como inteiros)
   b. Verificar: `a.endsWith(b)`
   c. Se verdadeiro: imprimir "encaixa"
   d. Se falso: imprimir "nao encaixa"

### Exemplo Passo a Passo

**Entrada:**
```
3
123456 456
123456 234
100 0
```

**Caso 1: A="123456", B="456"**
- "123456".endsWith("456")? SIM
- Saída: "encaixa"

**Caso 2: A="123456", B="234"**
- "123456".endsWith("234")? NÃO (234 está em posição 1-3, não no final)
- Saída: "nao encaixa"

**Caso 3: A="100", B="0"**
- "100".endsWith("0")? SIM (terminado em 0)
- Saída: "encaixa"

**Saída esperada:**
```
encaixa
nao encaixa
encaixa
```

### Implementação em Dart

A implementação utiliza:

- **Split de entrada**: Divide linha em 2 strings
- **Método endsWith()**: Verifica se string termina com outra
- **Condicional**: Imprime mensagem apropriada
- **stdout.writeln()**: Alternativa ao print (mais explícito)

### Complexidade

- **Tempo**: O(N × M) onde N = casos, M = comprimento de A (verificação de sufixo)
- **Espaço**: O(M) - armazenamento de strings A e B
