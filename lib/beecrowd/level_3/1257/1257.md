# 1257 - Array Hash

## Contexto

Você terá como uma entrada várias linhas, cada uma com uma string. O valor de cada caracter é computado como segue:

Valor = (Posição no alfabeto) + (Elemento de entrada) + (Posição do elemento)

Todas posições são baseadas em zero. 'A' tem posição 0 no alfabeto, 'B' tem posição 1 no alfabeto, ... O cálculo de hash retornado é a soma de todos os caracteres da entrada. Por exemplo, se a entrada for:
CBA
DDD

então cada caractere deverá ser computado como segue:

2 = 2 + 0 + 0 : 'C' no elemento 0 posição 0
2 = 1 + 0 + 1 : 'B' no elemento 0 posição 1
2 = 0 + 0 + 2 : 'A' no elemento 0 posição 2
4 = 3 + 1 + 0 : 'D' no elemento 1 posição 0
5 = 3 + 1 + 1 : 'D' no elemento 1 posição 1
6 = 3 + 1 + 2 : 'D' no elemento 1 posição 2

O cálculo final de hash será 2+2+2+4+5+6 = 21.

### Entrada

A entrada contém vários casos de teste. A primeira linha de entrada contém um inteiro N que indica a quantidade de casos de teste. Cada caso de teste inicia com um inteiro L (1 ≤ L ≤ 100) que indica a quantidade de linhas que vem a seguir. Cada uma destas L linhas contém uma string com até 50 letras maiúsculas ('A' - 'Z').

### Saída

Para cada caso de teste imprima o valor de hash que é calculado conforme o exemplo apresentado acima.

## Forma de resolução

Implementa hash customizado usando programação assíncrona. Lê entrada com `transform()` e `LineSplitter()` para processar múltiplos casos. Calcula hash como soma de: (posição da letra no alfabeto + linha + coluna).

## Descrição da Resolução

### Pensamento do Problema

Este problema envolve **processamento de entrada complexo e cálculo customizado de hash**:

- **Estrutura**: Múltiplos casos → Múltiplas linhas por caso → Múltiplos caracteres por linha
- **Cálculo por caractere**: `(posição_alfabeto) + (número_linha) + (posição_coluna)`
  - Posição no alfabeto: A=0, B=1, ..., Z=25 (calculado como `codeUnitAt(j) - 65`)
  - Número da linha: 0, 1, 2, ... (índice ii)
  - Posição na coluna: 0, 1, 2, ... (índice j)
- **Complexidade IO**: Stdin em Dart é síncrono no início, pode causar timeout
- **Solução**: Usar transformadores (`transform()`) para leitura assíncrona
- **Problema de timeout**: Versão original com `readLineSync()` dá TLE

### Abordagem da Solução (Versão Otimizada)

1. Usar `stdin.transform(utf8.decoder).transform(LineSplitter()).toList()` para ler toda entrada de uma vez (assíncrono)
2. Para cada caso de teste:
   a. Ler L (número de linhas)
   b. Para cada linha i (0 até L-1):
      - Ler string
      - Para cada caractere j (0 até length-1):
        - Calcular: `posAlfabeto + i + j`
        - Adicionar ao hash total
3. Imprimir hash para o caso

### Exemplo Passo a Passo

**Entrada:**
```
1
2
CBA
DDD
```

**Processamento (Caso 1):**
- L = 2 (duas linhas)
- Linha 0 (ii=0): "CBA"
  - j=0, C: (2) + (0) + (0) = 2
  - j=1, B: (1) + (0) + (1) = 2
  - j=2, A: (0) + (0) + (2) = 2
- Linha 1 (ii=1): "DDD"
  - j=0, D: (3) + (1) + (0) = 4
  - j=1, D: (3) + (1) + (1) = 5
  - j=2, D: (3) + (1) + (2) = 6
- Hash total: 2+2+2+4+5+6 = 21

**Saída:**
```
21
```

### Implementação em Dart

A implementação utiliza:

- **Entrada assíncrona**: `stdin.transform().transform().toList()` evita timeout
- **Parsing de linha**: `proximaLinha()` função auxiliar que pula linhas vazias
- **Cálculo de posição alfabeto**: `texto.codeUnitAt(j) - 65` (65 = ASCII 'A')
- **Loops aninhados**: 3 níveis (casos → linhas → caracteres)
- **Acumulação**: Variável hash que soma todos os valores

### Complexidade

- **Tempo**: O(N × L × M) onde N = casos, L = linhas por caso, M = caracteres por linha
- **Espaço**: O(N × L × M) - armazenamento de toda entrada
