Os testes chamam `canMariaWin(String)`, que usa a mesma lógica de `main()` sobre os bytes da entrada.

- **Exemplos:** os 4 casos do enunciado (`S`, `N`, `S`, `N`).
- **Força bruta:** para todo tabuleiro de tamanho 3 a 12 sem `XXX`, compara `canMariaWin` com uma busca minimax exaustiva (vence quem formar `XXX`; tabuleiro cheio sem `XXX` não é vitória). Cobre também o caminho otimizado de pré-computação de Grundy ($L \ge 5$).
- **Desempenho:** N = 10000 deve terminar bem abaixo de 3 s.

Total: 15 testes.
