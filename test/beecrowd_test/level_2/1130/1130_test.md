# Teste do problema 1130 - Jogo da Velha

## Objetivo do Teste

Validar a corretude do algoritmo de detecção de estratégia vencedora em um jogo da velha 1-D usando a teoria de Sprague-Grundy. Os testes cobrem:

1. **Casos do exemplo fornecido:** Validar que os 4 casos de entrada produzem as saídas esperadas.
2. **Casos de borda:** Tabuleiros com tamanho mínimo, padrões especiais e tabuleiro máximo.
3. **Vitória imediata:** Verificar detecção correta dos padrões `XX.`, `.XX`, `X.X`.
4. **Casas perigosas:** Validar identificação de casas até 2 posições de um `X`.
5. **Segmentos seguros:** Verificar divisão correta do tabuleiro em segmentos independentes.
6. **Valores de Grundy:** Testar pré-computação e cálculo recursivo dos valores de Grundy.

## Estrutura do Teste

### 1. Configuração (setUp)

```dart
setUp(() {
  solution.precomputeGrundy(10000);
});
```

A pré-computação dos valores de Grundy é feita uma única vez antes de cada grupo de testes para garantir consistência.

### 2. Grupos de Testes

#### Grupo: Casos do Exemplo

- **Caso 1:** `.....` → `S` (tabuleiro vazio, Maria vence)
- **Caso 2:** `..X..` → `N` (X no centro bloqueia segmentos)
- **Caso 3:** `X.X.X.` → `S` (padrão X.X = vitória imediata)
- **Caso 4:** `............` → `N` (XOR de Grundy = 0)

#### Grupo: Casos de Borda

- Tabuleiro mínimo `...` (N=3)
- Tabuleiro sem casas seguras
- Padrões de vitória imediata isolados
- Tabuleiro grande `....` (N=10000) para validar pré-computação

#### Grupo: Vitória Imediata

Testa os três padrões que completam uma sequência de 3 X:

- `XX.` — preenchendo a última posição
- `.XX` — preenchendo a primeira posição
- `X.X` — preenchendo a posição central

#### Grupo: Casas Perigosas

Valida que casas até 2 posições de um `X` são corretamente identificadas:

- X em posições diferentes (início, centro, final)
- Limites de borda do tabuleiro

#### Grupo: Segmentos Seguros

Verifica a divisão correta do tabuleiro em segmentos independentes:

- Sem X → um segmento
- Com X no centro → zero segmentos seguros
- Com X nas pontas → segmento no meio
- Múltiplos X → múltiplos segmentos

#### Grupo: Valores de Grundy

Testa a pré-computação:

- G(0) = 0, G(1) = 1, G(2) = 0, G(3) = 1
- Todos os valores são não-negativos
- Pré-computação até 10000 não causa erro

## Resultado Esperado

✅ **Todos os testes devem passar**, validando:

1. Corretude da detecção de vitória imediata
2. Corretude da identificação de casas perigosas
3. Corretude da extração de segmentos seguros
4. Corretude do cálculo de Grundy
5. Corretude da decisão final via XOR de Grundy
6. Performance adequada com pré-computação até N=10^4
